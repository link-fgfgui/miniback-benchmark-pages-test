What is measured

Only commits that change a file the engine tracks are replayed: .mca chunks, level.dat, playerdata/*.dat and data/**/*.dat. Commits that only touch documentation, logs, session.lock or level.dat_old are skipped. Every FULL and DELTA block is decompressed and byte-compared after writing.

The baseline is the packed git repository or the original compressed archive set. The vault is the engine's append-only store, including block headers and the block index cache.
