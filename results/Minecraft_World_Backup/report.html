Method, accounting and caveats

Model. Every snapshot is a complete world copy. Each is scanned into the targets the engine tracks: every non-empty chunk in region/, entities/ and poi/ .mca files (including custom dimensions), plus level.dat, playerdata/*.dat and every data/ .dat. All 21 versions are compared with the previous one by canonical NBT bytes, and the checkpoint policy is replayed: the first version writes a FULL baseline; a changed target appends a DELTA against its previous visible block; a new target appends FULL + an ABSENT marker; a deleted target appends an ABSENT marker; an unchanged target appends nothing. Every block is decompressed and byte-compared (roundtrip_fail).

Accounting. The 42-byte block header, the per-block index cache entry and the 28-byte per-file cache header are included. Filesystem block rounding and index.properties are not. "Full snapshot" is the cost of writing every current target as FULL with the same cache, i.e. what one independent full backup would cost.

Caveats. Diff is content-based, not write-capture: a target is "changed" only when its canonical bytes differ, so a server that rewrites identical data would append a small delta in production that is not charged here (the incremental numbers are a lower bound). Files outside the tracked NBT scope (datapacks, JSON, configs) are counted in "World" but not stored in the vault. Append-only, no GC or keyframes. Timings are a single warm-cache run on this machine, so treat them as indicative; byte counts are deterministic.

A commit is effective when it changes at least one file the engine tracks; commits that only touch README files, logs, session.lock or level.dat_old are skipped. Each effective commit is materialised into one live directory by tools/git_materialize.py immediately before it is scanned, and the preparation time is reported separately (prepare_ms). Source bytes are the sum of working-tree file sizes at that commit, i.e. an uncompressed checkout; the git repository size is the packed size reported by git count-objects. World roots: world.
